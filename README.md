¿qué archivo de Angular hace el papel de main.tsx, de App.tsx y de vite.config.ts?

main.tsx:es equivalente a main.ts que inicia la app angular

app.tsx: correponde al componente raiz que contiene logica y configuracion asi como la platinlla app.html

vite.config.ts:es la configuracion del proyecto y la que se encarga del proceso de compilacion que esta principalmente en angula.json
